Knowledge Graph RAG Project

Objective :
To extract entities and relationships from an agricultural schemes pdf and build a knowledge graph using Python and Neo4j AuraDB.

Requirements :
- PDF processing and entity extraction using an LLM
- JSON for storing extracted data
- Neo4j AuraDB for graph storage and visualization

What I Learned Today:
- Loading and processing PDF documents using Python.
- Extracting entities and relationships using an LLM.
- Connecting Python to Neo4j AuraDB.
- Creating graph nodes and relationships using Cypher.
- Understanding the importance of data cleaning and relationship validation.

Today's session established the initial knowledge graph pipeline, from PDF processing and entity extraction to Neo4j storage and visualization.
